# Add product FAQs to your storefront

Product FAQ Manager stores questions and answers with the Shopify product they belong to. To publish them, add the app block to a product template:

1. In Shopify Admin, open **Product FAQ Manager** and select a product.
2. Add or edit the product's questions and answers. Changes save directly to Shopify.
3. Choose **Open product template in Theme Editor**, or open **Online Store → Themes → Customize** yourself.
4. Open a product template, choose **Add block → Apps → Product FAQs**, and position the block.
5. Set the heading options if you want, then save the theme.

The block shows FAQs for the product being viewed. It stays hidden when a product has no saved FAQs. It works with Online Store 2.0 themes and product sections that support app blocks; it does not edit theme code.
